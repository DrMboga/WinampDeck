# Target board: Raspberry Pi 3 Model B, not the Pi 4

Status: accepted

WinampDeck was originally planned around a Raspberry Pi 4 (1GB RAM). In practice, the Digi Pro HAT clone this project uses failed to initialize on it: `dmesg` showed `wm8804 1-003b: Failed to read device ID: -121`, matching a real, documented hardware bug — Raspberry Pi 4B "Rev 1.5" boards (the standard production revision since late 2021) changed their PMIC, altering boot-time voltage-rail sequencing enough that HiFiBerry's original Digi+ Pro design can come up in a state its WM8804 chip won't answer on I2C. HiFiBerry had to revise their own hardware to fix it (Digi2 Pro v2.2); no software fix exists. The Pi in hand is confirmed Rev 1.5 (`cat /proc/cpuinfo`), and the clone's own hardware lineage relative to that fix is undocumented anywhere (research: [pi4-rev15-hat-compatibility.md](../../.tracker/controller-v1/research/pi4-rev15-hat-compatibility.md)).

A Raspberry Pi Zero 2 W was tried next — already confirmed working with this exact HAT — but raised two of its own problems: WiFi failed to associate at all (most likely the HAT's metal components sitting directly over the Zero's exposed corner-mounted antenna, though unconfirmed; a USB-Ethernet adapter was the only reliable network path found), and no benchmarked prior art exists for running go-librespot and mpv concurrently within its 512MB RAM budget — the closest comparable project found explicitly avoids running its own Connect and radio engines at the same time (research: [pi-zero-2w-feasibility.md](../../.tracker/controller-v1/research/pi-zero-2w-feasibility.md)).

A Raspberry Pi 5 at a similar price point was considered and set aside without full investigation: it moves GPIO/I2C/SPI off the direct-register architecture pigpio depends on ([ADR 0003](0003-cpp-controller-dependencies.md)) onto a new RP1 companion chip. Whether pigpio supports that at all was never confirmed — if it doesn't, the entire hardware-access layer would need rework, stacked on the same "does this clone's overlay even work here" uncertainty as the other options.

Decided: **Raspberry Pi 3 Model B (1GB RAM)**. It predates the Rev 1.5 PMIC change entirely — a stable, unchanged design since 2016 — shares the Pi 4's full-size Model B form factor and direct-register GPIO/I2C/SPI architecture (no rework needed for ADR 0003 or [docs/wiring.md](../wiring.md); the 40-pin layout is identical across the family), has a board-edge chip antenna rather than the Zero's exposed corner trace, and its 1GB RAM matches what the whole project was already planned around. One practical difference to carry forward: it powers over 5V/2.5A micro-USB, not the Pi 4's USB-C supply.
